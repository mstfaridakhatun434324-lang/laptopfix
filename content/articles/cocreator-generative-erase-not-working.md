You brush over an unwanted object in Paint, click generative erase, and nothing happens. Or the tool removes the object but leaves a smudge, a blur, or a patch that looks worse than the original. Sometimes the button is greyed out entirely, even though Cocreator itself still generates images. That split symptom is the clue: generation and erasure use related but different AI paths.

Generative erase needs a supported image, a current Paint build, working AI components, and enough processing power to fill the erased area convincingly. A huge image, a locked layer, an unsupported format, or a damaged model can each break it while leaving other Paint tools untouched. Large or complex selections are especially likely to fail, because the AI has more background to invent.

This guide isolates the cause, from image and selection checks to app repairs. If audio or network features are also unstable, they may point to a wider driver issue, so check the [Wi-Fi 7 speed fix](/articles/wifi-7-slow-speed-ai-laptop/) and the [microphone fix](/articles/ai-laptop-microphone-not-working/) for related troubleshooting. For a clean driver reinstall, see the [Intel NPU driver clean install guide](/articles/intel-npu-driver-clean-install-ddu/) before assuming Paint itself is broken.

## Why this happens

- **Unsupported image format or size:** Generative erase works best on common formats at reasonable sizes, and huge or unusual files can fail outright.
- **Paint version too old:** The feature arrived and improved through Paint updates, so an outdated build may lack it or contain an erase bug.
- **AI components missing or damaged:** If the on-device models are incomplete, generation may work while erase, which uses a different model path, fails.
- **Selection too large or complex:** Erasing a huge area forces the AI to invent too much background, which often produces smudges or errors.
- **Corrupt Paint cache:** Damaged app data can break one AI tool while leaving brushes, layers, and basic editing untouched.
- **Hardware or driver limits:** A missing NPU driver or low available memory can cause erase to time out on larger selections.

## How to fix it

Work through these in order — diagnose first, then act.

### Fix 1: Test erase on a small, simple image first
Before repairing anything, prove whether erase is broken everywhere or only on one image. Open a simple photo, select a small object against a plain background, and try generative erase there. If it works on the simple image, your original file or selection is the problem, not Paint. If it fails everywhere, move on to updates and repairs with confidence.
1. Open a simple JPEG photo with a small object on a plain background.
2. Use the selection tool to select only the object, with a small margin.
3. Apply generative erase and wait for processing to finish fully.
4. Compare the result with the original to judge whether it worked.
5. If it works here, the issue is your original image or selection size.

### Fix 2: Prepare the image properly before erasing
Image preparation fixes more erase failures than any repair tool. Convert unusual formats to PNG or JPEG, resize oversized images to a manageable width, and work on a copy so you can retry. Smaller, cleaner inputs give the AI less background to invent and far fewer chances to smudge, which is why professionals resize before erasing rather than after.
1. Make a copy of your image and edit the copy, not the original.
2. Convert unusual formats to PNG or JPEG using Paint Save As.
3. Resize very large images to under 4000 pixels on the longest side.
4. Select tightly around the object, avoiding extra background where possible.
5. Try erase again on the prepared copy and check the result closely.

### Fix 3: Update Paint and Windows for the latest erase support
Generative erase has improved significantly across Paint updates, and an older build may simply contain the bug you are hitting. Updating Paint through the Store and Windows through Settings ensures you have the latest erase model and fixes. Restart after updating, because AI components often finish installing only after a reboot.
1. Open the Microsoft Store and install any available Paint updates.
2. Go to Settings, Windows Update, and install all offered updates.
3. Restart your laptop after both updates have finished.
4. Open Paint and confirm generative erase appears in the toolbar.
5. Test erase on the simple image from Fix 1 before retrying your original.

### Fix 4: Use smaller selections and erase in stages
A single huge selection is the most common cause of smudged results. Erasing in stages gives the AI a smaller area to fill each time, and each stage uses the previous clean result as its background. This technique also lets you stop as soon as one stage looks wrong, rather than losing a whole large edit to one bad generation.
1. Select only part of the unwanted object, not the whole thing at once.
2. Apply generative erase to that section and wait for it to finish.
3. Check the result closely before selecting the next section.
4. Repeat in small stages until the whole object is removed.
5. If one stage smudges, undo that stage only and retry it smaller.

### Fix 5: Repair Paint and check AI components
When erase fails on every image, including simple ones, Paint or its AI components are likely damaged. Repairing Paint through Settings preserves your saved files and often restores erase without a full reset. System file tools then fix deeper damage, and a successful online generation test afterwards confirms the AI path is healthy again.
1. Go to Settings, Apps, Installed apps, and find Paint.
2. Select Advanced options, then Repair, and wait for completion.
3. Open Terminal as administrator and run sfc /scannow if needed.
4. Then run DISM /Online /Cleanup-Image /RestoreHealth for the store.
5. Restart, open Paint, and test generative erase on a simple image.

### Fix 6: Reset Paint and retry with a clean setup
If repair does not restore erase, a reset clears corrupt data that repair leaves behind. Save your work first, then reset Paint, update it again, and test on a simple image before returning to your original project. A clean setup resolves the stubborn cases where one AI tool fails while every other Paint feature works normally.
1. Save all open Paint work to a folder before resetting anything.
2. Go to Settings, Apps, Installed apps, Paint, Advanced options.
3. Select Reset, then restart your laptop to clear cached data.
4. Reopen Paint and install any Store updates offered after reset.
5. Test generative erase on a simple image, then on your prepared copy.
6. For current support notes, check the official [Windows support pages](https://support.microsoft.com/en-us/windows) for Paint feature availability.

## Closing

Generative erase fails most often because of the image, the selection, or the Paint build, not because the AI itself is broken. Testing on a simple image, preparing the file properly, erasing in stages, and updating Paint resolves the large majority of cases. Keep a copy of every original before erasing, so a bad result costs you a retry rather than a lost photo.
